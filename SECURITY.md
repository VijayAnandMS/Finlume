# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Finlume AI, please send an e-mail directly instead of opening an issue. 

We will acknowledge your email within 48 hours and work with you on resolving the issue rapidly. 

We implement strict `slowapi` bounds and JWT hashes—if you observe orchestration bypasses, immediately notify the repo owner.
