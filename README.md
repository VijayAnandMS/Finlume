# Finlume AI

An AI-powered personal finance platform built with a modern agentic architecture.

## Tech Stack

### Backend
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication

### Frontend
- React
- TypeScript
- Vite

### AI
- Claude / Gemini
- Tool Calling
- Multi-Agent Orchestrator

## Current Features

- JWT Authentication
- Dashboard
- Expense Agent
- Budget Agent
- Multi-agent AI Orchestrator
- Provider switching (.env)
- REST API architecture
